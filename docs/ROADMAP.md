# Roadmap de producto y operaciones — IncidentOps

| Hito | Resultado de negocio |
|---|---|
| H001 — Triaje multi-interfaz | Exponer la clasificación y el enrutamiento determinista de reportes sin persistencia, para consumo inmediato desde web y terminal. |
| H002 — Resumen de incidentes activos | Consultar incidentes actualmente activos, incumplimientos de SLA y filtrado por componente desde web y terminal. |
| H003 — Ciclo de vida, duplicados y SLA | Registrar incidentes entrantes de forma persistente, alertar si existe otro equivalente abierto y auditar su SLA en cualquier instante de referencia. |
| H004 — Persistencia relacional dedicada y runtime en contenedores | Preparar la ejecución reproducible en contenedores con base de datos relacional dedicada y chequeo real de conectividad operativa. |
